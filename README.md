Mini Gestionale Dipendenti

# Funzionalità

- Visualizzazione dei dipendenti
- Ricerca di un dipendente per nome
- Ricerca del dipendente con lo stipendio più alto
- Inserimento di nuovi dipendenti
- Menu interattivo

# Tecnologie

- Python
- Git
- GitHub

# Avvio

Per eseguire il programma:
python main.py

# Obiettivo

Il progetto è stato realizzato per mettere in pratica i principali concetti della programmazione Python, tra cui:

- variabili e tipi di dato
- liste e dizionari
- cicli `for` e `while`
- condizioni `if/elif/else`
- funzioni
- parametri e valori restituiti
- gestione dell'input dell'utente
