# Mini Gestionale Dipendenti

## Funzionalità

- Visualizzazione dei dipendenti
- Ricerca di un dipendente per nome
- Ricerca del dipendente con lo stipendio più alto
- Inserimento di nuovi dipendenti
- Modifica dei dati di un dipendente
- Eliminazione di un dipendente
- Visualizzazione dello stipendio medio
- Menu interattivo
- Validazione degli input
- Test automatici

## Tecnologie

- Python
- SQLite
- SQL
- Pytest
- Git
- GitHub

## Avvio

Per eseguire il programma:
python main.py

## Test

Per eseguire i test automatici:
python -m pytest

## Obiettivo

Il progetto è stato realizzato per mettere in pratica i principali concetti della programmazione Python e della gestione di un'applicazione con database, tra cui:
- variabili e tipi di dato
- liste e dizionari
- cicli for e while
- condizioni if/elif/else
- funzioni
- parametri e valori restituiti
- gestione dell'input dell'utente
- gestione di un database SQLite
- operazioni CRUD
- validazione degli input
- test automatici con Pytest
- utilizzo di Git e GitHub

## Struttura del progetto

- main.py → gestisce il menu principale e richiama le funzioni del programma.
- database.py → gestisce il database SQLite e le operazioni sui dipendenti.
- validazione.py → gestisce la validazione degli input inseriti dall'utente.
- tests/ → contiene i test automatici per verificare il corretto funzionamento del programma.
